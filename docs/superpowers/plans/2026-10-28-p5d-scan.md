# P5d: Scan and the New First View Implementation Plan

> **For agentic workers:** implement this plan task-by-task with the `executing-plans` skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Ate something else" gets option 1C's first view: usual orders first, then "Not in your usuals?" with a Scan row and "Type the numbers instead". Scan reads a barcode on the phone and looks it up in Open Food Facts through a cached Worker endpoint, or, with the AI on, reads a photo of the nutrition label. Either way the person lands on option 3B's product card and logs it with `logOffPlan`. The Describe it row stays hidden until P5e.

**Architecture:**
- **Pure rules, tested in Node:**
    - `app/ai/barcode.ts`: the GTIN check digit, UPC-E expansion, the code a scan read, digit grouping, and the `Product` type both sides share.
    - `app/ai/label.ts`: the label sanity check.
    - `app/ai/photo.ts`: the 1,568 px downscale and JPEG encode.
    - `app/today/offplan.ts`: the first view's choice rows, and everything the product card shows and logs.
- **The Worker:**
    - `app/ai/off.server.ts` parses Open Food Facts and caches each answer in `caches.default`. `GET /api/food/barcode/:code` (in the new `workers/api/food.ts`) needs a session but nothing AI: no key, no switch, no cap.
    - `POST /api/ai/label` ships here, as P5a's plan hands it on: `AiClient.label` (a vision call with structured output, low effort) and the `aiLabel` handler in `workers/api/ai.ts`, on P5a's gate, cap (20 a day) and `ai_calls` log. The photo goes to the model and nowhere else.
- **The phone:** `app/ai/client.ts` gains `findBarcode` (its own GET with a timeout) and `readLabel` (on P5a's `postAi`). `app/ai/scanner.ts` loads the `barcode-detector` ponyfill with a dynamic `import()` and points zxing at our own copy of the `.wasm`, which the service worker precaches. The sheet reads P5a's `useAi()` for the switch, the key and the signal.
- **The sheet:** `OffPlanSheet` keeps one `Sheet` and switches views: usuals, Something new, Scan, the product card. `Sheet` gains a back button. Project 3's form moves to `SomethingNewForm` unchanged, with optional starting values.

**Tech Stack:** React Router 8.4 in SPA mode (after P4f), Cloudflare Workers with the Cache API, `barcode-detector` 3.2.3 (zxing-wasm 3.1.6), Zod 4, Tailwind 4 with the Corner tokens, Vitest 4 (`unit` in Node, `workers` against real D1 through `@cloudflare/vitest-plugin`).

## Calls made in this plan (flag them when shipping)

- **`POST /api/ai/label` is built here,** as P5a's plan moved each AI route to the step that uses it. It follows P5b's take route: P5a's gate, a 400 for a bad body, the cap, one call, one `ai_calls` row.
- **The label route's fallback shape is an unreadable label:** a model failure answers 200 with `readable: false` and every field null, so the phone shows "Couldn't read that label." whether the panel was unreadable or the call failed. The `ai_calls` row says which.
- **The barcode route lives in a new `workers/api/food.ts`,** beside P5a's `workers/api/ai.ts`, because it is not AI and none of the AI gate applies.
- **"Under 5 MB" is the base64 string's length,** 5,000,000 characters, which is also Anthropic's per-image limit. A 1,568 px JPEG at 0.8 is well under it.
- **The label's Zod schema lives in `app/ai/label.ts`,** which runs on both sides: the Worker sends it as the structured-output format, and the phone parses the reply with it.
- **The `.wasm` is imported with Vite's `?url`, not copied into `public/`.** The build emits it under `/assets/` with a content hash, so it is still our own asset, and a zxing upgrade can never serve a stale binary. The precache list gains `.wasm` files, and the service worker's `/assets/` cache-first rule already serves it offline.
- **UPC-E is expanded to its UPC-A before the check digit and the lookup.** The spec lists `upc_e` among the formats and checks "GTIN-8, 12, 13 or 14", but a UPC-E's check digit belongs to the 12-digit code it stands for.
- **A 12-digit code is looked up and cached as 13 digits** (a leading 0), the form Open Food Facts answers with, so a UPC-A read and an EAN-13 read of the same can share one cache entry.
- **OFF down is its own answer:** `{ found: false, down: true }`, status 200, never cached. The spec's contract only names `{ found: false }`; the phone needs to tell the two apart for "Open Food Facts didn't answer."
- **A bad code is a 400** (`{ error: "Not a barcode" }`), so a typo'd curl doesn't reach OFF.
- **The product card's view is titled "Ate something else"**, as mock 3B draws it, with the back button every later view has. The scan views are titled "Scan".
- **The choice rows use an ink outline,** as the 1C mock draws them. The spec's table says `border`.
- **With the AI off, the not-found line drops its second sentence:** "Barcode 0 81162 00219 8 has no listing." The label it points to is hidden.
- **The camera-blocked view also offers a quiet "Type the numbers"**, which the spec's copy ("or type the numbers") implies.
- **A product with no name** shows "Scanned item" on the card, so the log always has a name.
- **The grams stepper logs its grams in the name:** "Nutella, 40 g". The spec only gives the servings suffix.
- **Product card stepper:** Servings 1 to 10; Grams from 100 g in 10 g steps, 10 g to 1,000 g.
- **Log it is disabled above 5,000 calories**, `logOffPlan`'s own limit, so ten servings of something huge never fails on push.
- **A label read with no protein** counts 0 g protein. A label read with no calories is "Couldn't read that label."
- **"Numbers look wrong? Edit them"** fills the form with the plain name, without the servings suffix, and the numbers for the servings shown.
- **If the decoder fails to load** (the `.wasm` didn't arrive), the Scan view shows the camera-blocked copy, which still offers the label and typing.
- **New icons:** `pencil` and `barcode` join the icon set, drawn as the 1C mock draws them. P5d uses `barcode`; P5e uses `pencil`.

```ts
// Barcodes: read on the phone, looked up on the Worker. Pure, so both sides share it.

/** One Open Food Facts product, as the product card shows it. */
export interface Product {
  code: string;
  name: string;
  /** "1 bottle (414 g)". Null when Open Food Facts has only per-100 g numbers. */
  servingText: string | null;
  /** Per serving, or per 100 g when `servingText` is null. */
  kcal: number;
  proteinG: number;
  /** Open Food Facts files it under beverages. */
  drink: boolean;
}

/** GS1 mod 10: weights 3 and 1 from the right, over every digit but the last. */
export function gtinValid(code: string): boolean {
  if (!/^(\d{8}|\d{12}|\d{13}|\d{14})$/.test(code)) return false;
  const digits = [...code].map(Number);
  const check = digits.pop()!;
  const sum = digits.reverse().reduce((total, d, i) => total + d * (i % 2 === 0 ? 3 : 1), 0);
  return (10 - (sum % 10)) % 10 === check;
}

/** A UPC-E as the 12-digit UPC-A it stands for. Its check digit belongs to the UPC-A. */
export function expandUpcE(code: string): string | null {
  if (!/^[01]\d{7}$/.test(code)) return null;
  const d = code.slice(1, 7);
  const last = d[5]!;
  let body: string;
  if (last <= "2") body = `${d.slice(0, 2)}${last}0000${d.slice(2, 5)}`;
  else if (last === "3") body = `${d.slice(0, 3)}00000${d.slice(3, 5)}`;
  else if (last === "4") body = `${d.slice(0, 4)}00000${d[4]}`;
  else body = `${d.slice(0, 5)}0000${last}`;
  return `${code[0]}${body}${code[7]}`;
}

/** The code to look up from one detector result, or null when the read is wrong and scanning should go on. */
export function scannedCode(rawValue: string, format: string): string | null {
  const code = format === "upc_e" ? expandUpcE(rawValue) : rawValue;
  return code !== null && gtinValid(code) ? code : null;
}

/** "0 85239 00417 2" for UPC-A, "3 017620 422003" for EAN-13, one run of digits otherwise. */
export function groupDigits(code: string): string {
  if (/^\d{12}$/.test(code)) return `${code[0]} ${code.slice(1, 6)} ${code.slice(6, 11)} ${code[11]}`;
  if (/^\d{13}$/.test(code)) return `${code[0]} ${code.slice(1, 7)} ${code.slice(7)}`;
  return code;
}
```

```ts
const FIELDS = "code,product_name,brands,serving_size,serving_quantity,nutriments,categories_tags";
const KJ_PER_KCAL = 4.184;

/** Open Food Facts answers in 13 digits, so a UPC-A is asked for (and cached) that way too. */
export function offCode(code: string): string {
  return code.length === 12 ? `0${code}` : code;
}

export function offUrl(code: string): string {
  return `https://world.openfoodfacts.org/api/v2/product/${code}?fields=${FIELDS}`;
}

// Open Food Facts sends numbers as numbers or as numeric strings.
function num(v: unknown): number | undefined {
  const n = typeof v === "number" ? v : typeof v === "string" && v.trim() !== "" ? Number(v) : NaN;
  return Number.isFinite(n) ? n : undefined;
}

function energy(n: Record<string, unknown>, basis: "100g" | "serving"): number | undefined {
  const kcal = num(n[`energy-kcal_${basis}`]);
  if (kcal !== undefined) return kcal;
  const kj = num(n[`energy-kj_${basis}`]);
  return kj === undefined ? undefined : kj / KJ_PER_KCAL;
}

function productName(p: Record<string, unknown>): string {
  const name = typeof p.product_name === "string" ? p.product_name.trim() : "";
  const brand = typeof p.brands === "string" ? (p.brands.split(",")[0] ?? "").trim() : "";
  const full = brand && !name.toLowerCase().startsWith(brand.toLowerCase()) ? `${brand} ${name}`.trim() : name || brand;
  return (full || "Scanned item").slice(0, 80);
}

/** The card's product, or null when Open Food Facts has no listing or no calories for it. */
export function parseOff(code: string, json: unknown): Product | null {
  const doc = json as { status?: unknown; product?: Record<string, unknown> } | null;
  if (!doc || doc.status !== 1 || !doc.product) return null;
  const p = doc.product;
  const n = (p.nutriments ?? {}) as Record<string, unknown>;
  const kcal100 = energy(n, "100g");
  const protein100 = num(n.proteins_100g);
  const kcalServing = energy(n, "serving");
  const quantity = num(p.serving_quantity);
  const servingSize = typeof p.serving_size === "string" && p.serving_size.trim() ? p.serving_size.trim().slice(0, 40) : null;

  let kcal: number;
  let protein: number;
  let servingText: string | null;
  if (kcalServing !== undefined) {
    kcal = kcalServing;
    protein = num(n.proteins_serving) ?? (protein100 !== undefined && quantity ? (protein100 * quantity) / 100 : 0);
    servingText = servingSize ?? "1 serving";
  } else if (kcal100 !== undefined && quantity && quantity > 0) {
    kcal = (kcal100 * quantity) / 100;
    protein = ((protein100 ?? 0) * quantity) / 100;
    servingText = servingSize ?? `1 serving (${quantity} g)`;
  } else if (kcal100 !== undefined) {
    kcal = kcal100;
    protein = protein100 ?? 0;
    servingText = null;
  } else {
    return null;
  }

  const categories = Array.isArray(p.categories_tags) ? p.categories_tags : [];
  return {
    code: typeof p.code === "string" && p.code ? p.code : code,
    name: productName(p),
    servingText,
    kcal: Math.round(kcal),
    proteinG: Math.round(protein * 10) / 10,
    drink: categories.includes("en:beverages"),
  };
}
```

```ts
const USER_AGENT = "TheCorner/2.0 (https://kampduh.com)";
const CACHE_PREFIX = "https://kampduh.com/__off/";
const HIT_SECONDS = 30 * 24 * 60 * 60;
const MISS_SECONDS = 24 * 60 * 60;
const TIMEOUT_MS = 6_000;

export type BarcodeAnswer = { found: true; product: Product } | { found: false; down?: true };

/** One barcode, from the cache or from Open Food Facts. A down or slow OFF is never cached, so the next scan asks again. */
export async function lookupBarcode(code: string, cache: Cache = caches.default): Promise<BarcodeAnswer> {
  const key = offCode(code);
  const cacheKey = new Request(`${CACHE_PREFIX}${key}`);
  const hit = await cache.match(cacheKey);
  if (hit) return (await hit.json()) as BarcodeAnswer;

  let json: unknown;
  try {
    const res = await fetch(offUrl(key), { headers: { "User-Agent": USER_AGENT }, signal: AbortSignal.timeout(TIMEOUT_MS) });
    // OFF answers an unknown code with a 404 and a JSON body; anything else not ok means it is struggling.
    if (!res.ok && res.status !== 404) return { found: false, down: true };
    json = await res.json();
  } catch {
    return { found: false, down: true };
  }

  const product = parseOff(key, json);
  const answer: BarcodeAnswer = product ? { found: true, product } : { found: false };
  await cache.put(cacheKey, Response.json(answer, { headers: { "Cache-Control": `max-age=${product ? HIT_SECONDS : MISS_SECONDS}` } }));
  return answer;
}
```

```ts
const LONG_EDGE = 1568;
const QUALITY = 0.8;

export function fitLongEdge(width: number, height: number, max = LONG_EDGE): { width: number; height: number } {
  const scale = Math.min(1, max / Math.max(width, height));
  return { width: Math.round(width * scale), height: Math.round(height * scale) };
}

/**
 * The photo as base64 JPEG for the label route: 1,568 px on its long edge at 0.8. Nothing is kept: the bitmap is
 * closed and the canvas dropped once this returns, and the caller drops the file.
 */
export async function jpegForUpload(file: Blob): Promise<string> {
  const bitmap = await createImageBitmap(file, { imageOrientation: "from-image" });
  try {
    const { width, height } = fitLongEdge(bitmap.width, bitmap.height);
    const canvas = document.createElement("canvas");
    canvas.width = width;
    canvas.height = height;
    canvas.getContext("2d")!.drawImage(bitmap, 0, 0, width, height);
    const blob = await new Promise<Blob>((resolve, reject) => canvas.toBlob((b) => (b ? resolve(b) : reject(new Error("JPEG encode failed"))), "image/jpeg", QUALITY));
    const bytes = new Uint8Array(await blob.arrayBuffer());
    let binary = "";
    for (let i = 0; i < bytes.length; i += 0x8000) binary += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
    return btoa(binary);
  } finally {
    bitmap.close();
  }
}
```

```ts
const BARCODE_MS = 10_000;
const LABEL_MS = 20_000;

/** JSON from a GET, or null for no signal, a timeout, a non-200 answer or a body that isn't JSON. */
async function getWithin(path: string, timeoutMs: number, send: typeof fetch): Promise<unknown> {
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), timeoutMs);
  try {
    const res = await send(path, { signal: ctrl.signal });
    return res.ok ? await res.json() : null;
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}

const ProductSchema = z.object({
  code: z.string(),
  name: z.string(),
  servingText: z.string().nullable(),
  kcal: z.number(),
  proteinG: z.number(),
  drink: z.boolean(),
});
const BarcodeSchema = z.union([z.object({ found: z.literal(true), product: ProductSchema }), z.object({ found: z.literal(false), down: z.boolean().optional() })]);

export type BarcodeLookup = { found: true; product: Product } | { found: false; down: boolean };

/** A scanned code looked up through the Worker. No signal and a slow Open Food Facts both read as down. */
export async function findBarcode(code: string, timeoutMs = BARCODE_MS, send: typeof fetch = fetch): Promise<BarcodeLookup> {
  const parsed = BarcodeSchema.safeParse(await getWithin(`/api/food/barcode/${code}`, timeoutMs, send));
  if (!parsed.success) return { found: false, down: true };
  return parsed.data.found ? parsed.data : { found: false, down: parsed.data.down === true };
}

/** What the label photo says, or null for any fallback: the caller shows "Couldn't read that label." */
export async function readLabel(image: string, timeoutMs = LABEL_MS, send: typeof fetch = fetch): Promise<LabelRead | null> {
  const parsed = LabelSchema.safeParse(await postAi<unknown>("/api/ai/label", { image }, timeoutMs, send));
  return parsed.success ? parsed.data : null;
}
```

```ts
export interface Choice {

  label: string;
  sub: string;
  disabled: boolean;
}

/** The rows under "Not in your usuals?". `aiReady`: the person's switch is on and the server has a key. */
export function offPlanChoices({ aiReady, online }: { aiReady: boolean; online: boolean }): Choice[] {
  const label = aiReady ? "Scan" : "Scan a barcode";
  if (!online) return [{ kind: "scan", label, sub: "Needs a signal", disabled: true }];
  return [{ kind: "scan", label, sub: aiReady ? "Barcode or label" : "Looks it up in Open Food Facts", disabled: false }];

/** What the product card shows, from a barcode or a label. Numbers are per serving, or per 100 g with no serving. */
export interface CardSource {
  /** Null from a label with no printed name: the card asks for one. */
  name: string | null;
  servingText: string | null;
  kcal: number;
  proteinG: number;
  from: "barcode" | "label";
  drink: boolean;
}

/** The Something new form's starting values. */
export interface FormValues {
  name: string;
  category: "meal" | "snack" | "dessert" | "drink";
  kcal: number;
  protein: number;
}

export function cardFromProduct(p: Product): CardSource {
  return { name: p.name, servingText: p.servingText, kcal: p.kcal, proteinG: p.proteinG, from: "barcode", drink: p.drink };
}

export function sourceLine(c: CardSource): string {
  return `Per ${c.servingText ?? "100 g"} · ${c.from === "barcode" ? "Open Food Facts" : "From the label"}`;
}

export interface CardStepper {
  label: "Servings" | "Grams";
  start: number;
  min: number;
  max: number;
  step: number;
  /** After the number on the stepper: "" for servings, " g" for grams. */
  unit: string;
}

export function stepperFor(c: CardSource): CardStepper {
  return c.servingText === null ? { label: "Grams", start: 100, min: 10, max: 1000, step: 10, unit: " g" } : { label: "Servings", start: 1, min: 1, max: 10, step: 1, unit: "" };
}

const NAME_MAX = 80;

function totals(c: CardSource, count: number): { kcal: number; protein: number } {
  const times = c.servingText === null ? count / 100 : count;
  return { kcal: Math.round(c.kcal * times), protein: Math.round(c.proteinG * times) };
}

const categoryOf = (c: CardSource): FormValues["category"] => (c.from === "barcode" && c.drink ? "drink" : "snack");

/** What Log it sends to `logOffPlan`, less the ids, date, relaxed (off) and Save as a usual. */
export function cardLog(c: CardSource, count: number, name: string): { name: string; category: FormValues["category"]; kcal: number; proteinG: number } {
  const suffix = c.servingText === null ? `, ${count} g` : count > 1 ? `, ${count} servings` : "";
  const t = totals(c, count);
  return { name: `${name.trim().slice(0, NAME_MAX - suffix.length)}${suffix}`, category: categoryOf(c), kcal: t.kcal, proteinG: t.protein };
}

/** "Numbers look wrong? Edit them": the form, filled with the plain name and the numbers for the count shown. */
export function cardEdit(c: CardSource, count: number, name: string): FormValues {
  const t = totals(c, count);
  return { name: name.trim().slice(0, NAME_MAX), category: categoryOf(c), kcal: t.kcal, protein: t.protein };
}

export type LabelOutcome = { kind: "card"; card: CardSource } | { kind: "form"; values: FormValues; note: string } | { kind: "unreadable" };

/** Where a label read lands: the card, the form with a warning, or "Couldn't read that label." */
export function labelOutcome(read: LabelRead | null): LabelOutcome {
  if (!read || !read.readable || read.kcal === null) return { kind: "unreadable" };
  const proteinG = read.proteinG ?? 0;
  if (!labelSane(read.kcal, proteinG)) {
    return { kind: "form", values: { name: read.name ?? "", category: "snack", kcal: Math.round(read.kcal), protein: Math.round(proteinG) }, note: "These numbers look off. Check them against the label." };
  }
  return { kind: "card", card: { name: read.name, servingText: read.servingText ?? "1 serving", kcal: read.kcal, proteinG, from: "label", drink: false } };
}
```

```ts
import wasmUrl from "zxing-wasm/reader/zxing_reader.wasm?url";
import { scannedCode } from "./barcode";

const EVERY_MS = 200;
const FORMATS = ["ean_13", "ean_8", "upc_a", "upc_e"];

export interface Detected {
  rawValue: string;
  format: string;
}

/** A detector for the four retail formats. The .wasm comes from our own assets, never jsDelivr, so it works offline. */
export async function loadDetector(): Promise<{ detect: (source: HTMLVideoElement) => Promise<Detected[]> }> {
  const { BarcodeDetector, prepareZXingModule } = await import("barcode-detector/ponyfill");
  await prepareZXingModule({
    overrides: { locateFile: (path: string, prefix: string) => (path.endsWith(".wasm") ? wasmUrl : prefix + path) },
    fireImmediately: true,
  });
  return new BarcodeDetector({ formats: FORMATS as never });
}

/** Looks for a code about 5 times a second until one passes its check digit. Returns a stop function. */
export function startScanning(detect: () => Promise<Detected[]>, onCode: (code: string) => void, everyMs = EVERY_MS): () => void {
  let stopped = false;
  let timer: ReturnType<typeof setTimeout> | undefined;
  const look = async () => {
    if (stopped) return;
    let code: string | null = null;
    try {
      for (const d of await detect()) code ??= scannedCode(d.rawValue, d.format);
    } catch {
      // A frame that fails to decode is skipped.
    }
    if (stopped) return;
    if (code) {
      stopped = true;
      onCode(code);
      return;
    }
    timer = setTimeout(look, everyMs);
  };
  timer = setTimeout(look, 0);
  return () => {
    stopped = true;
    clearTimeout(timer);
  };
}
```

`FORMATS as never` is there because the ponyfill types `formats` as its own string union; the four names are in it.

```tsx
                })}
                className={`${btn.outline} h-11 px-3.5 text-[16px]`}
              >
                Remove
              </button>
            ) : (
              <button
                type="button"
                onClick={tap(() => {
                  void mutate("logUsual", { clientId: crypto.randomUUID(), usual: u.key, date });
                  onLogged();
                })}
                className={`${btn.outline} h-11 px-3.5 text-[16px]`}
              >
                Log
              </button>
            )}
          </li>
        ))}
      </ul>
      {!all && usuals.length > USUALS_SHOWN && (
        <button type="button" onClick={() => setAll(true)} className={btn.quiet}>
          All {usuals.length} usuals
        </button>
      )}
    </div>
  );
}
```
