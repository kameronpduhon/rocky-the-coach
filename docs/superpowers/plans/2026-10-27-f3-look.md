# F3: The Look Implementation Plan

> **For agentic workers:** implement this plan task-by-task with the `executing-plans` skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every screen wears "Corner revised". That means warm paper, ink, self-hosted Anton, Barlow and Barlow Semi Condensed, a red focus ring and the new text-only tab bar. v1 screens keep their layouts until their own projects rebuild them.

**Architecture:**
- **One token file.** `app/styles/tokens.css` holds the new palette. It also re-points every v1 colour variable at a new token, so v1 screens change colour without touching their markup.
- **Solid surfaces.** The glass classes become solid paper with an ink border. The shared v1 controls (switch, segmented control, sheet) take the mock's shapes, and radius 14 to 34 px collapses to the mock's 6 px across the app.
- **Fonts.** They come from `@fontsource` (latin subsets only). The three faces on every first screen are preloaded, and the service worker's existing cache-first rule for `/assets/` keeps them offline.
- **Contrast.** A unit test parses the token file and fails the build if a text pairing drops under 4.5:1.

**Tech Stack:** Tailwind CSS 4 (`@theme inline`), `@fontsource/anton`, `@fontsource/barlow`, `@fontsource/barlow-semi-condensed`, React Router 8.4, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-10-27-foundation-design.md`, section 3 and rollout step 3. **Branch:** `v2/f3-look` (already created from `main` after F2 merged).

**Calls made in this plan (not separately approved, flag them in the PR):**
- **The `app/ui/` component kit moves to F4.** Each component gets built with the screen that first uses it, so its props come from real use. F3 restyles the v1 shared controls in place instead. `GymFrame` moves to project 2, which is the first to use it.
- **Status bar.** It switches from `black-translucent` to `default`. With translucent, iOS draws the clock in white, which disappears on paper. With `default`, content no longer runs under the status bar, so the fixed 54 px top padding becomes `max(16px, env(safe-area-inset-top))`.
- **The app becomes light only.** The dark-mode block in `tokens.css` is deleted (spec: dark mode is out of scope, and Kameron wants light).
- **12 px text exception.** 12 px is allowed only for bold condensed micro labels ("NEXT", chart axis labels), as the approved Today mock does. Every other text stays at 13 px or larger.
- **v1 data colours collapse to three inks:** protein `--ink`, steps `--ink-3`, calories `--muted`. Red never marks food, and green is gone.

## Ground rules

- Everything from F1's and F2's ground rules applies:
    - No em dashes in code, copy, commits or docs.
    - No `Co-Authored-By` lines.
    - Look with `npm run dev`, never `npm run build`.
    - One full `npm run typecheck && npm test` at the end, not after every task.
- No new colours. Every colour in markup is a token class (`bg-paper`, `text-ink`, `border-border`) or a v1 class that now resolves to a token. If a step seems to need a new hex, stop and say so in the report.
- Red (`--red`) is only for the primary action and live state (the rest timer, today, the active tab, the focus ring). Brass is only for progression.
- Do not change layouts, copy or behaviour on v1 screens beyond what a task says.

```ts
import { readFileSync } from "node:fs";
import path from "node:path";
import { describe, expect, it } from "vitest";

const css = readFileSync(path.join(import.meta.dirname, "../../app/styles/tokens.css"), "utf8");

const declared = new Map<string, string>();
for (const [, name, value] of css.matchAll(/--([\w-]+):\s*([^;]+);/g)) declared.set(name, value.trim());

function hex(name: string, seen = new Set<string>()): string {
  const value = declared.get(name);
  if (!value) throw new Error(`--${name} is not declared`);
  const alias = value.match(/^var\(--([\w-]+)\)$/);
  if (alias) {
    if (seen.has(name)) throw new Error(`--${name} refers to itself`);
    return hex(alias[1], seen.add(name));
  }
  if (!/^#[0-9a-f]{6}$/i.test(value)) throw new Error(`--${name} is ${value}, expected a hex or a var()`);
  return value;
}

function luminance(h: string) {
  const [r, g, b] = [1, 3, 5].map((i) => parseInt(h.slice(i, i + 2), 16) / 255).map((v) => (v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4));
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

function contrast(fg: string, bg: string) {
  const [a, b] = [luminance(hex(fg)), luminance(hex(bg))].sort((x, y) => y - x);
  return (a + 0.05) / (b + 0.05);
}

describe("Corner revised tokens", () => {
  it("is light only", () => {
    expect(css).not.toContain("prefers-color-scheme");
  });

  it.each([
    ["ink", "paper"],
    ["ink-2", "paper"],
    ["ink-3", "paper"],
    ["muted", "paper"],
    ["muted", "raised"],
    ["muted", "well"],
    ["ink-3", "field"],
    ["red", "paper"],
    ["red", "raised"],
    ["on-red", "red"],
    ["brass-on", "brass-tag"],
    ["ink-2", "brass-fill"],
    ["coral", "ink"],
    ["paper", "ink"],
    ["on-ink-2", "ink"],
    // v1 names, as v1 screens use them
    ["label", "bg"],
    ["label-2", "card"],
    ["label-3", "bg"],
    ["label-on-fill", "fill"],
    ["steps-text", "card"],
    ["calories", "calories-chip-bg"],
    ["protein", "protein-chip-bg"],
    ["prominent-label", "prominent-fill"],
  ])("--%s text on --%s is at least 4.5:1", (fg, bg) => {
    expect(contrast(fg, bg)).toBeGreaterThanOrEqual(4.5);
  });

  it.each([
    ["border", "paper"],
    ["border", "raised"],
    ["brass-border", "brass-fill"],
  ])("--%s outline on --%s is at least 3:1", (fg, bg) => {
```

```tsx
import { NavLink, useNavigation } from "react-router";

const TABS = [
  { to: "/", label: "Today" },
  { to: "/plan", label: "Plan" },
  { to: "/progress", label: "Progress" },
  { to: "/library", label: "Library" },
] as const;

export function TabBar() {
  // Light the tapped tab at once instead of after its data arrives, and only that one.
  const pending = useNavigation().location?.pathname;
  const pendingTab = pending ? TABS.find((t) => (t.to === "/" ? pending === "/" : pending.startsWith(t.to)))?.to : undefined;
  return (
    <>
      {/* The bar is fixed, so the page keeps its height in flow and the last row scrolls clear. */}
      <div aria-hidden="true" className="h-[calc(58px+env(safe-area-inset-bottom))] flex-none min-[900px]:hidden" />
      <nav
        aria-label="Main"
        className="fixed inset-x-0 bottom-0 z-20 grid grid-cols-4 border-t-2 border-ink bg-paper px-2 pt-1 pb-[env(safe-area-inset-bottom)] font-num text-[15px] font-bold uppercase tracking-[0.04em]

      >
        {TABS.map((t) => (
          <NavLink
            key={t.to}
            to={t.to}
            end={t.to === "/"}
            className={({ isActive }) =>
              `flex h-[52px] items-center justify-center min-[900px]:justify-start ${(pendingTab ? pendingTab === t.to : isActive) ? "text-red" : "text-muted"}`
            }
          >
            {t.label}
          </NavLink>
        ))}
      </nav>
    </>
  );
}
```

```js
(() => {
  const rgba = (s) => s.match(/[\d.]+/g).map(Number);
  const lum = ([r, g, b]) => [r, g, b].map((v) => ((v /= 255) <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4)).reduce((a, v, i) => a + v * [0.2126, 0.7152, 0.0722][i], 0);
  const bgOf = (el) => {
    for (let e = el; e; e = e.parentElement) {
      const c = rgba(getComputedStyle(e).backgroundColor);
      if (c.length === 3 || c[3] >= 0.5) return c.slice(0, 3);
    }
    return [243, 238, 228];
  };
  const bad = [];
  for (const el of document.querySelectorAll("body *")) {
    if (![...el.childNodes].some((n) => n.nodeType === 3 && n.textContent.trim())) continue;
    const cs = getComputedStyle(el);
    if (cs.visibility === "hidden" || el.closest("[aria-hidden=true]") || !el.getClientRects().length) continue;
    const size = parseFloat(cs.fontSize);
    const [a, b] = [lum(rgba(cs.color)), lum(bgOf(el))].sort((x, y) => y - x);
    const ratio = (a + 0.05) / (b + 0.05);
    const large = size >= 24 || (size >= 18.66 && Number(cs.fontWeight) >= 700);
    const text = el.textContent.trim().slice(0, 40);
    if (ratio < (large ? 3 : 4.5)) bad.push(`contrast ${ratio.toFixed(2)} ${el.tagName} "${text}"`);
    if (size < 13) bad.push(`size ${size}px ${el.tagName} "${text}"`);
  }
  return bad.length ? bad.join("\n") : "all text passes";
})()
```
