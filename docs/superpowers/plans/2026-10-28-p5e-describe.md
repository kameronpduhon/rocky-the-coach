# P5e: Describe It Implementation Plan

> **For agentic workers:** implement this plan task-by-task with the `executing-plans` skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Describe it" joins the first view of "Ate something else". The person types a meal like a text; the model splits it into foods with grams and maps each to an id in a USDA-derived food table the app ships; the rules compute calories and protein from the table and show option 2A's editable plate, which logs through `logOffPlan`. The model never writes a calorie or protein number that gets logged.

**Architecture:**
- **The food table** is `content/food-table.json`: 334 common foods, each with a USDA FoodData Central id, calories and protein per 100 g, and a few portions. It is generated by `scripts/build-food-table.ts` from the hand-kept `content/food-table.source.json` and FDC's public-domain bulk downloads, run by hand and committed. `content/foods.json` is unchanged.
- **Pure rules, tested in Node:**
    - `app/ai/food-table.ts`: the parsed table, lookups, the picker's search, and the describe prompt's food block (ids, names, aliases and portions; never a number per 100 g).
    - `app/ai/plate.ts`: plate rows from the model's items, row and total math, the stepper, "+ oil", picked foods, typed numbers.
- **The Worker:** `POST /api/ai/describe` ships here, as P5a's plan hands it on: `AiClient.describe` (structured output, low effort, the food table as a cached system block), `tidyDescribe` (12 foods, 1 to 2,000 g, only the table's ids) and the `aiDescribe` handler in `workers/api/ai.ts`, on P5a's gate, cap (30 a day) and `ai_calls` log.
- **The phone:** `describeMeal` in `app/ai/client.ts`, on P5a's `postAi` (20 seconds, then the fallback). The sheet reads P5a's `useAi()` as P5d left it. Two new views in the off-plan sheet, Describe it and the plate, and a food picker sheet over the plate.

**Tech Stack:** React Router 8.4 in SPA mode, Cloudflare Workers, `@anthropic-ai/sdk` (P5a's client, `claude-sonnet-5-5`), Zod 4, Tailwind 4, `tsx` for the build script, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-10-28-rocky-ai-design.md`: section 1 (Endpoints, "The model call": prompt caching), section 3 ("The first view (1C)", "Describe it", "The plate (2A)", "The math", "The food picker"), section 6 ("Content: the food table"), section 7, section 8 step 5, Testing ("Plate", "Content", "View models", "/api/ai/describe", "On the wire"). **Options board:** picked 1C and 2A (`p5-options/index.html` in the session scratchpad). **Branch:** `v2/p5-rocky-ai`, worktree `/Users/kameron/Code/rocky-wt/p5`. **Previous step:** `docs/superpowers/plans/2026-10-28-p5d-scan.md`, which must be live.

## The food table: where the numbers come from

- **Primary: FDC's bulk JSON downloads,** no key needed, pinned by file name so a rerun gives the same numbers:
    - SR Legacy: `https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_json_2018-04.zip` (13 MB, 210 MB unzipped, key `SRLegacyFoods`). Includes the "Fast Foods" and "Restaurant Foods" groups.
    - Foundation: `https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_foundation_food_json_2026-04-30.zip` (key `FoundationFoods`).
    - FNDDS (Survey): `https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_survey_food_json_2024-10-31.zip` (66 MB unzipped as `surveyDownload.json`, key `SurveyFoods`).
    - All three were downloaded and parsed on 2026-10-28 while writing this plan; every one of the 334 `fdcId`s in the source list resolved, and Appendix A holds the numbers they gave.
- **Fallback 1: the FDC API,** same public-domain data by the same ids: `POST https://api.nal.usda.gov/fdc/v1/foods?api_key=DEMO_KEY` with `{ "fdcIds": [...up to 20], "format": "full" }`. 17 requests; `DEMO_KEY` allows 30 an hour. A real key from api.data.gov goes in `FDC_API_KEY` if `DEMO_KEY` is rate-limited.
- **Fallback 2: the checked list in Appendix A,** the numbers the bulk files gave on 2026-10-28, one row per food with its `fdcId` as the citation. The script reads it with `--checked`.
- **How a number is read:** calories are FDC nutrient 208 (Energy, kcal); Foundation foods without 208 use 957 (Atwater General Factors), then 958 (Atwater Specific); a food with only kJ (268) uses kJ / 4.184. Protein is nutrient 203. Calories round to whole numbers, protein to 2 decimals. 957 before 958 matches `content/foods.json`, whose Foundation lettuce reads 22.
- **What the 334 are:** the plan's pantry, cooked and raw (same ids as `content/foods.json`); Chipotle-style components (thigh, steak, carnitas, barbacoa, rice, beans, fajita veg, four salsas, guacamole, queso, cheese, sour cream, tortillas, chips); breads and tortillas; beans; sauces and dressings; cheeses; snacks and sweets; beer, wine, spirits, soda and the coffee drinks; and burgers, fries, nuggets, pizza, tacos, burritos, subs, sushi and Chinese takeout from SR Legacy's fast-food and restaurant groups and FNDDS.
- **Portions** are hand-kept in the source list. Where FDC lists a portion, the grams are FDC's; restaurant scoops are typical weights (113 g for a 4 oz scoop).

## Calls made in this plan (flag them when shipping)

- **`POST /api/ai/describe` is built here,** as P5a's plan moved each AI route to the step that uses it. It follows P5b's take route and P5d's label route.
- **Out-of-range model output is tidied, not refused:** past 12 foods are dropped, grams are clamped to 1 to 2,000 and rounded, names cut to 60, and an id the table lacks becomes `null` (spec section 7). Only a reply that isn't the schema's shape is `bad-output`.
- **The route's fallback shape is `{ items: null }`:** it fails `DescribeSchema`, so the phone shows "couldn't build that plate". An empty `items` array is the model finding no food, and shows "couldn't find any foods".
- **334 foods, not "about 300",** so every component of a Chipotle bowl, a fast-food order and a bar tab has a row. The prompt's food block is about 6,700 tokens, not the spec's 5,000: a describe costs about $0.022 cold and less inside the 5-minute cache.
- **Three plan foods carry USDA numbers that differ from `foods.json`,** which took them from labels: `whey-protein` (352 cal, 78.1 g, SR Legacy "Protein powder whey based" against the label's 400 and 80), `salsa` (34 and 1.44, FNDDS red salsa, against 30 and 1.5) and `cocktail-sauce` (128 and 1.36 against 120 and 1.5). `coconut-aminos` is left out (FDC has no entry); "coconut aminos" is an alias on soy sauce. Every other plan food matches `foods.json`.
- **Protein keeps 2 decimals in the table,** as FDC gives it. The plate rounds per row anyway.
- **A row at 0 g counts 0 and is not "uncounted":** stepping a food down to 0 is how you take it off the plate, so it shouldn't nag.
- **Typed numbers show exactly as typed** until the grams change. Then they scale and round like a matched row (calories to 5, protein to 1).
- **The stepper:** up is +5 g under 50 g and +10 g from 50 g, to 2,000 g; down is −5 g at 50 g and under and −10 g above, to 0. So 50 goes up to 60 and down to 45.
- **A food picked from "+ sauce" starts at its first portion,** as the spec says for drinks (for example 2 tbsp of ranch, 30 g). "Pick a food" on an unmatched row keeps the row's grams.
- **Log it is disabled above 5,000 calories,** `logOffPlan`'s own limit, as on the product card.
- **The picker's protein reads in whole grams** ("132 cal · 9 g per 100 g"); the table keeps the decimals.
- **The picker opens as its own sheet over the plate,** rendered inside the plate view; Done closes only the picker.
- **"What you said" sits in a well-coloured box** with "Edit" on the right, as mock 2A draws it.
- **New copy the spec doesn't give:**
    - The picker with nothing matching: "No food in the table matches that."
    - The picker's group headings (see `GROUP_LABEL` in Task 2).
    - Log it disabled past 5,000: "That's past 5,000 cal. Check the grams."
    - A nameless plate from the model is titled "Something else".

- [ ] **Step 1: The schemas.** Append to `app/content/schema.ts`:

```ts
export const FOOD_GROUPS = ["protein", "starch", "beans", "tortilla-bread", "vegetable", "fruit", "dairy", "fat-oil", "sauce", "snack-sweet", "drink", "fast-food"] as const;
export type FoodGroup = (typeof FOOD_GROUPS)[number];

/** One food in content/food-table.source.json, kept by hand. */
export const FoodTableSourceSchema = z.object({
  id: z.string().regex(/^[a-z0-9-]+$/),
  name: z.string().min(1).max(60),
  /** Other names, for the picker's search and for the model. */
  aliases: z.array(z.string().min(1)),
  group: z.enum(FOOD_GROUPS),
  fdcId: z.number().int().positive(),
  source: z.enum(["foundation", "sr-legacy", "fndds"]),
  portions: z.array(z.object({ label: z.string().min(1), g: z.number().positive() })).min(1),
});
export type FoodTableSource = z.infer<typeof FoodTableSourceSchema>;

/** One food in content/food-table.json: the source entry with FDC's numbers per 100 g. */
export const FoodTableEntrySchema = FoodTableSourceSchema.extend({
  kcalPer100: z.number().min(0).max(900),
  proteinPer100: z.number().min(0).max(100),
});
export type FoodTableEntry = z.infer<typeof FoodTableEntrySchema>;
```

In `tsconfig.node.json`, add `"app/content/schema.ts"` to `include`, after `"app/sync/tables.ts"`.

```ts
// Builds content/food-table.json: content/food-table.source.json with calories and protein per 100 g from USDA
// FoodData Central (public domain). Run by hand; commit the output.
//
// Usage:
//   npx tsx scripts/build-food-table.ts                    downloads FDC's three bulk JSON files (about 300 MB unzipped)
//   npx tsx scripts/build-food-table.ts --dir <path>       reuses files already downloaded and unzipped there
//   npx tsx scripts/build-food-table.ts --api              asks the FDC API instead (FDC_API_KEY, or DEMO_KEY)
//   npx tsx scripts/build-food-table.ts --checked <tsv>    uses a checked list: the P5e plan's Appendix A
import { execFileSync } from "node:child_process";
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { tmpdir } from "node:os";
import path from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";
import { FoodTableEntrySchema, FoodTableSourceSchema, type FoodTableEntry, type FoodTableSource } from "../app/content/schema";

export const FDC_FILES = [
  { url: "https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_json_2018-04.zip", json: "FoodData_Central_sr_legacy_food_json_2018-04.json", key: "SRLegacyFoods" },
  { url: "https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_foundation_food_json_2026-04-30.zip", json: "FoodData_Central_foundation_food_json_2026-04-30.json", key: "FoundationFoods" },
  { url: "https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_survey_food_json_2024-10-31.zip", json: "surveyDownload.json", key: "SurveyFoods" },
];
const API = "https://api.nal.usda.gov/fdc/v1/foods";
const API_BATCH = 20;
const KJ_PER_KCAL = 4.184;

export interface FdcNutrient {
  nutrient?: { number?: string };
  amount?: number;
}
export interface FdcFood {
  fdcId: number;
  foodNutrients: FdcNutrient[];
}
export interface Numbers {
  kcalPer100: number;
  proteinPer100: number;
}

function amount(nutrients: FdcNutrient[], number: string): number | undefined {
  return nutrients.find((x) => x.nutrient?.number === number && typeof x.amount === "number")?.amount;
}

/** Energy (208); Foundation foods may only have Atwater General (957) or Specific (958); else kJ (268). */
export function energyKcal(nutrients: FdcNutrient[]): number | undefined {
  const kcal = amount(nutrients, "208") ?? amount(nutrients, "957") ?? amount(nutrients, "958");
  if (kcal !== undefined) return kcal;
  const kj = amount(nutrients, "268");
  return kj === undefined ? undefined : kj / KJ_PER_KCAL;
}

export function numbersOf(food: FdcFood): Numbers | undefined {
  const kcal = energyKcal(food.foodNutrients);
  const protein = amount(food.foodNutrients, "203");
  if (kcal === undefined || protein === undefined) return undefined;
  return { kcalPer100: Math.round(kcal), proteinPer100: Math.round(protein * 100) / 100 };
}

export function buildFoodTable(source: FoodTableSource[], numbers: Map<number, Numbers>): FoodTableEntry[] {
  const missing = source.filter((s) => !numbers.has(s.fdcId)).map((s) => `${s.id} (${s.fdcId})`);
  if (missing.length) throw new Error(`No FDC numbers for: ${missing.join(", ")}`);
  return source.map((s) => FoodTableEntrySchema.parse({ ...s, ...numbers.get(s.fdcId)! }));
}

export function readChecked(tsv: string): Map<number, Numbers> {
  const rows = tsv.trim().split("\n").slice(1);
  return new Map(
    rows.map((line) => {
      const [, fdcId, kcal, protein] = line.split("\t");
      return [Number(fdcId), { kcalPer100: Number(kcal), proteinPer100: Number(protein) }];
    }),
  );
}

async function fromDownloads(dir: string, ids: Set<number>): Promise<Map<number, Numbers>> {
  mkdirSync(dir, { recursive: true });
  const out = new Map<number, Numbers>();
  for (const f of FDC_FILES) {
    const jsonPath = path.join(dir, f.json);
    if (!existsSync(jsonPath)) {
      console.log(`Downloading ${f.url}`);
      const res = await fetch(f.url);
      if (!res.ok) throw new Error(`${f.url}: HTTP ${res.status}`);
      const zip = path.join(dir, path.basename(f.url));
      writeFileSync(zip, Buffer.from(await res.arrayBuffer()));
      execFileSync("unzip", ["-o", "-q", zip, "-d", dir]);
    }
    const foods = (JSON.parse(readFileSync(jsonPath, "utf8")) as Record<string, (FdcFood | null)[]>)[f.key] ?? [];
    for (const food of foods) {
      if (!food || !ids.has(food.fdcId)) continue;
      const n = numbersOf(food);
      if (n) out.set(food.fdcId, n);
    }
  }
  return out;
}

async function fromApi(ids: number[]): Promise<Map<number, Numbers>> {
  const key = process.env.FDC_API_KEY ?? "DEMO_KEY";
  const out = new Map<number, Numbers>();
  for (let i = 0; i < ids.length; i += API_BATCH) {
    const res = await fetch(`${API}?api_key=${key}`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ fdcIds: ids.slice(i, i + API_BATCH), format: "full" }) });
    if (!res.ok) throw new Error(`FDC API: HTTP ${res.status}`);
    for (const food of (await res.json()) as FdcFood[]) {
      const n = numbersOf(food);
      if (n) out.set(food.fdcId, n);
    }
  }
  return out;
}

async function main() {
  const root = fileURLToPath(new URL("..", import.meta.url));
  const args = process.argv.slice(2);
  const flag = (name: string) => {
    const i = args.indexOf(name);
    return i === -1 ? undefined : args[i + 1];
  };
  const source = FoodTableSourceSchema.array().parse(JSON.parse(readFileSync(path.join(root, "content/food-table.source.json"), "utf8")));
  const ids = [...new Set(source.map((s) => s.fdcId))];

  let numbers: Map<number, Numbers>;
  if (args.includes("--api")) numbers = await fromApi(ids);
  else if (flag("--checked")) numbers = readChecked(readFileSync(flag("--checked")!, "utf8"));
  else numbers = await fromDownloads(flag("--dir") ?? path.join(tmpdir(), "rocky-fdc"), new Set(ids));

  const table = buildFoodTable(source, numbers);
  writeFileSync(path.join(root, "content/food-table.json"), `[\n${table.map((f) => `  ${JSON.stringify(f)}`).join(",\n")}\n]\n`);
  console.log(`Wrote ${table.length} foods to content/food-table.json`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  main().catch((err) => {
    console.error(err instanceof Error ? err.message : err);
    process.exit(1);
  });
}

// The food table (content/food-table.json, from USDA FoodData Central). The model maps foods to its ids; the rules
// read its numbers. Runs on the phone and the Worker.
import tableJson from "../../content/food-table.json";
import { FOOD_GROUPS, FoodTableEntrySchema, type FoodGroup, type FoodTableEntry } from "~/content/schema";

export const FOOD_TABLE: readonly FoodTableEntry[] = FoodTableEntrySchema.array().parse(tableJson);
export const FOOD_BY_ID: ReadonlyMap<string, FoodTableEntry> = new Map(FOOD_TABLE.map((f) => [f.id, f]));

export const isFoodId = (id: string): boolean => FOOD_BY_ID.has(id);

/** The picker's group headings, in the table's group order. */
export const GROUP_LABEL: Record<FoodGroup, string> = {
  protein: "Meat, fish and eggs",
  starch: "Rice, pasta and potatoes",
  beans: "Beans",
  "tortilla-bread": "Tortillas and bread",
  vegetable: "Vegetables",
  fruit: "Fruit",
  dairy: "Dairy and cheese",
  "fat-oil": "Oils, nuts and butters",
  sauce: "Sauces and dressings",
  "snack-sweet": "Snacks and sweets",
  drink: "Drinks",
  "fast-food": "Restaurant and fast food",
};

export interface FoodSection {
  group: FoodGroup;
  label: string;
  foods: FoodTableEntry[];
}

/** The picker's list: every word of the query in the name or an alias, within one group or all of them. */
export function searchFoods(query: string, group: FoodGroup | null): FoodSection[] {
  const words = query.toLowerCase().split(/\s+/).filter(Boolean);
  const hit = (f: FoodTableEntry) => {
    const text = [f.name, ...f.aliases].join(" ").toLowerCase();
    return words.every((w) => text.includes(w));
  };
  return FOOD_GROUPS.filter((g) => group === null || g === group)
    .map((g) => ({ group: g, label: GROUP_LABEL[g], foods: FOOD_TABLE.filter((f) => f.group === g && hit(f)) }))
    .filter((s) => s.foods.length > 0);
}

/** The describe prompt's cached block. Ids, names, aliases and portions; never a number per 100 g. */
export function foodPromptBlock(): string {
  const lines = FOOD_TABLE.map((f) => `${f.id} | ${f.name} | ${f.aliases.join(", ")} | ${f.portions.map((p) => `${p.label} ${p.g} g`).join(", ")}`);
  return ["Food table. One food per line: id | name | other names | common portions.", ...lines].join("\n");
}
```

// The plate (option 2A): one row per food the model named, numbers from the food table, never from the model.
import type { FoodTableEntry } from "~/content/schema";

export type Foods = ReadonlyMap<string, FoodTableEntry>;

export interface PlateRow {
  key: string;
  /** The model's words for the food. An unmatched row shows them. */
  label: string;
  /** A food-table id, or null when the table has no match. */
  foodId: string | null;
  grams: number;
  /** Numbers typed on an unmatched row, and the grams showing when they were typed. */
  typed: { kcal: number; protein: number; grams: number } | null;
}

export interface Numbers {
  kcal: number;
  protein: number;
}

const MAX_ITEMS = 12;
const MAX_GRAMS = 2000;
export const OIL_ID = "cooking-oil";
const OIL_GRAMS = 10;

const round5 = (n: number) => Math.round(n / 5) * 5;

const nextKey = (rows: PlateRow[]) => `row-${rows.length}`;

export function startPlate(items: { label: string; foodId: string | null; grams: number }[], foods: Foods): PlateRow[] {
  return items.slice(0, MAX_ITEMS).map((item, i) => ({
    key: `row-${i}`,
    label: item.label,
    foodId: item.foodId !== null && foods.has(item.foodId) ? item.foodId : null,
    grams: Math.min(MAX_GRAMS, Math.max(1, Math.round(item.grams))),
    typed: null,
  }));
}

/** A row's numbers as shown, or null for an unmatched row nobody has typed numbers into yet. */
export function rowNumbers(row: PlateRow, foods: Foods): Numbers | null {
  if (row.grams === 0) return { kcal: 0, protein: 0 };
  const food = row.foodId === null ? undefined : foods.get(row.foodId);
  if (food) return { kcal: round5((row.grams * food.kcalPer100) / 100), protein: Math.round((row.grams * food.proteinPer100) / 100) };
  if (!row.typed) return null;
  if (row.typed.grams === row.grams || row.typed.grams === 0) return { kcal: row.typed.kcal, protein: row.typed.protein };
  const scale = row.grams / row.typed.grams;
  return { kcal: round5(row.typed.kcal * scale), protein: Math.round(row.typed.protein * scale) };
}

/** The sum of the rows as shown, so the numbers on screen add up. */
export function plateTotal(rows: PlateRow[], foods: Foods): Numbers {
  return rows.reduce((t, r) => {
    const n = rowNumbers(r, foods);
    return n ? { kcal: t.kcal + n.kcal, protein: t.protein + n.protein } : t;
  }, { kcal: 0, protein: 0 });
}

export function uncountedNote(rows: PlateRow[], foods: Foods): string | null {
  const left = rows.filter((r) => rowNumbers(r, foods) === null);
  if (left.length === 0) return null;
  return left.length === 1 ? `${left[0]!.label} isn't counted until it has numbers.` : `${left.length} foods aren't counted until they have numbers.`;
}

export const stepUp = (g: number): number => Math.min(MAX_GRAMS, g + (g < 50 ? 5 : 10));
export const stepDown = (g: number): number => Math.max(0, g - (g <= 50 ? 5 : 10));

const update = (rows: PlateRow[], key: string, change: (r: PlateRow) => PlateRow) => rows.map((r) => (r.key === key ? change(r) : r));

export function setGrams(rows: PlateRow[], key: string, grams: number): PlateRow[] {
  return update(rows, key, (r) => ({ ...r, grams }));
}

/** The Cal and Protein g fields on an unmatched row. No calories means no numbers yet. */
export function typeNumbers(rows: PlateRow[], key: string, typed: { kcal: number | null; protein: number | null }): PlateRow[] {
  return update(rows, key, (r) => ({ ...r, typed: typed.kcal === null ? null : { kcal: Math.round(typed.kcal), protein: Math.round(typed.protein ?? 0), grams: r.grams } }));
}

export function addOil(rows: PlateRow[], foods: Foods): PlateRow[] {
  const oil = rows.find((r) => r.foodId === OIL_ID);
  if (oil) return setGrams(rows, oil.key, Math.min(MAX_GRAMS, oil.grams + OIL_GRAMS));
  return [...rows, { key: nextKey(rows), label: foods.get(OIL_ID)?.name ?? "Cooking oil", foodId: OIL_ID, grams: OIL_GRAMS, typed: null }];
}

/** A food from "+ sauce" or "+ drink", at its first portion. */
export function addFood(rows: PlateRow[], food: FoodTableEntry): PlateRow[] {
  return [...rows, { key: nextKey(rows), label: food.name, foodId: food.id, grams: Math.round(food.portions[0]!.g), typed: null }];
}

/** "Pick a food" on an unmatched row: the picked food at the same grams. */
export function pickFood(rows: PlateRow[], key: string, food: FoodTableEntry): PlateRow[] {
  return update(rows, key, (r) => ({ ...r, label: food.name, foodId: food.id, typed: null }));
}

// Describe-a-meal (spec section 3). The model only splits the text into foods with grams and maps each to a
// food-table id. The phone computes every calorie and protein number from the table.
import { z } from "zod";

const MAX_ITEMS = 12;
const MAX_GRAMS = 2000;
const NAME_MAX = 60;

/** The model's reply, and the route's. Lengths and counts are tidied by tidyDescribe, not refused. */
export const DescribeSchema = z.object({
  name: z.string(),
  category: z.enum(["meal", "snack", "dessert", "drink"]),
  items: z.array(z.object({ label: z.string(), foodId: z.string().nullable(), grams: z.number() })).max(40),
});
export type DescribeReply = z.infer<typeof DescribeSchema>;

/** The route's answer when the model failed. It fails DescribeSchema, so the phone reads it as no plate. */
export const NO_PLATE = { items: null };

/** The reply as the plate takes it: at most 12 foods, whole grams from 1 to 2,000, and only the table's ids. */
export function tidyDescribe(reply: DescribeReply, isFood: (id: string) => boolean): DescribeReply {
  return {
    name: reply.name.trim().slice(0, NAME_MAX).trim() || "Something else",
    category: reply.category,
    items: reply.items.slice(0, MAX_ITEMS).map((i) => ({
      label: i.label.trim().slice(0, NAME_MAX),
      foodId: i.foodId !== null && isFood(i.foodId) ? i.foodId : null,
      grams: Math.min(MAX_GRAMS, Math.max(1, Math.round(i.grams))),
    })),
  };
}

import { useId, useState } from "react";
import { describeMeal } from "~/ai/client";
import type { DescribeReply } from "~/ai/describe";
import { COACH_NAME } from "~/brand";
import { btn } from "~/ui/button";
import { describeProblem } from "./offplan";

const MAX_CHARS = 300;

/** Describe it: a text box, and the model's foods on the plate. Failures keep the text in the box. */
export function DescribeView({ startText, onPlate, onType }: { startText: string; onPlate: (text: string, reply: DescribeReply) => void; onType: () => void }) {
  const id = useId();
  const [text, setText] = useState(startText);
  const [busy, setBusy] = useState(false);
  const [problem, setProblem] = useState<string | null>(null);

  const build = async () => {
    const said = text.trim();
    if (!said || busy) return;
    setBusy(true);
    setProblem(null);
    const reply = await describeMeal(said);
    setBusy(false);
    const why = describeProblem(reply);
    if (why || !reply) setProblem(why);
    else onPlate(said, reply);
  };

  return (
    <div className="flex flex-col gap-3">
      <label htmlFor={id} className="text-[13px] font-semibold text-ink-3">
        What did you eat?
      </label>
      <textarea
        id={id}
        rows={4}
        maxLength={MAX_CHARS}
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Chipotle bowl, double chicken, white rice, black beans, fajita veg, salsa, guac"
        className="rounded-[6px] border-[1.5px] border-border bg-field px-3 py-2.5 text-[17px] leading-[1.4] text-ink"
      />
      <p className="text-[15px] leading-[1.4] text-ink-3">{COACH_NAME} splits it into foods. The food table sets the calories and protein.</p>
      {problem && (
        <p role="alert" className="text-[15px] leading-[1.4] text-ink-2">
          {problem}
        </p>
      )}
      <button type="button" disabled={busy || !text.trim()} onClick={() => void build()} className={`${btn.primary} mt-1 h-14 disabled:opacity-50`}>
        {busy ? "Building the plate" : "Build the plate"}
      </button>
      <button type="button" onClick={onType} className={btn.quiet}>

      </button>

function GramStepper({ label, grams, onChange }: { label: string; grams: number; onChange: (grams: number) => void }) {
