# Exercise Library: Image Mapping

Every exercise in the plan mapped to its entry in [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain, Unlicense). Each entry has two photos: `0.jpg` and `1.jpg`, the start and end of the movement (the order varies by exercise). Showing both, or flipping between them, gives a sense of the motion without video.

Image URL pattern: `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/<id>/<0|1>.jpg`. The build copies the images we use into our own storage rather than hotlinking GitHub.
